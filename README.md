# 屿录 · Prompt Recorder

在线使用：[https://yu-record-studio.zilchtokyo.chatgpt.site](https://yu-record-studio.zilchtokyo.chatgpt.site)

一个在浏览器本地完成合成、录制与格式转换的高画质提词录制器。它可以把屏幕、摄像头、麦克风、系统声音和提词字幕实时合成为视频，素材不会上传到服务器。

## 已实现

- 屏幕、窗口或浏览器标签页录制
- 最高请求 4K 的摄像头画中画
- 麦克风降噪、回声消除和系统声音混合
- 电脑声音与麦克风独立音量调节（0–200%，录制中实时生效）
- 电脑声音与麦克风双通道实时 dBFS 响度表、峰值保持和削波提示
- 原始分辨率、4K、1080p 输出
- 30 / 60 fps 与 20 / 40 / 60 Mbps 码率选择
- WebM、MP4、MOV 视频与 24-bit / 48 kHz WAV 音频导出
- Chrome 语音识别驱动的自适应提词滚屏
- 文案提词与“说什么显示什么”的实时字幕模式
- 中文、English 和中英混合（中文为主）识别模式
- 从提词文案自动提取英文词汇，并支持英文术语/人名词库、多候选结果校正
- 根据语音停顿自动断句，并分别使用中英文标点
- 不支持语音识别时可用的匀速滚屏
- 字幕仅预览或写入成片切换
- 提词字号、颜色、背景深度、位置、区域宽高和进度控制
- 摄像头位置、大小、圆角/圆形与镜像控制
- 轻微对比度和饱和度增强
- 暂停、继续、停止、回放与本地下载
- 主动关闭屏幕共享，以及未下载上一段录制时的离页与覆盖提醒
- 提词器和画中画独立设置面板
- 文案和界面设置自动保存在当前浏览器

## 本地运行

需要 Node.js 20.9 或更高版本。

```bash
npm install
npm run dev
```

然后在 Chrome 中打开 [http://localhost:3000](http://localhost:3000)。

## 使用顺序

1. 选择要录制的屏幕、窗口或标签页。
2. 按需开启摄像头与麦克风。要录制电脑声音，请优先共享 Chrome 标签页并勾选“共享标签页音频”；接入后可分别调整电脑声音和麦克风音量。
3. 选择“文案提词”粘贴原稿，或选择“实时字幕”直接识别实际说话内容。
4. 选择文件格式、分辨率、帧率和码率后开始录制。
5. 停止录制，等待本地处理完成后回看并下载文件。

## 浏览器限制

- 推荐 macOS 最新版 Chrome。
- 语音跟随依赖 Chrome 的 Web Speech API 和系统默认麦克风，识别服务是否可用取决于浏览器、网络与地区。
- Web Speech API 每次请求只有一个主语言。“中英混合”以中文为主，并用文案英文、术语库和多候选结果提高英文词汇命中率；整段英文请切换到 English。
- 术语上下文增强属于实验性浏览器能力；不支持时会自动保留多候选校正，不会中断字幕。
- 浏览器拒绝语音权限时，匀速滚屏仍可使用。
- 浏览器只能请求设备支持的最高画质，摄像头不支持 4K 时会自动使用其实际分辨率。
- 高码率 4K / 60fps 对 CPU、GPU 和磁盘压力较大，建议连接电源并关闭高负载应用。
- MP4 与 MOV 会在录制结束后于浏览器本地转换，4K 长视频需要更多处理时间和内存。
- “仅自己看”不会把字幕合成到录制画布；如果共享的是本页面或整个显示器，屏幕采集仍可能拍到可见界面。
- 非 localhost 环境必须使用 HTTPS，浏览器才会开放屏幕、摄像头和麦克风权限。
