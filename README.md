# 屿录 · Prompt Recorder

在线使用：[https://yu-record-studio.zilchtokyo.chatgpt.site](https://yu-record-studio.zilchtokyo.chatgpt.site)

一个在浏览器本地完成合成与录制的高画质提词录制器。它可以把屏幕、摄像头、麦克风、系统声音和提词字幕实时合成为一个 WebM 视频，素材不会上传到服务器。

## 已实现

- 屏幕、窗口或浏览器标签页录制
- 最高请求 4K 的摄像头画中画
- 麦克风降噪、回声消除和系统声音混合
- 原始分辨率、4K、1080p 输出
- 30 / 60 fps 与 20 / 40 / 60 Mbps 码率选择
- Chrome 语音识别驱动的自适应提词滚屏
- 不支持语音识别时可用的匀速滚屏
- 提词字号、颜色、背景深度、位置、区域宽度和进度控制
- 摄像头位置、大小、圆角/圆形与镜像控制
- 轻微对比度和饱和度增强
- 暂停、继续、停止、回放与本地下载
- 文案和界面设置自动保存在当前浏览器

## 本地运行

需要 Node.js 20.9 或更高版本。

```bash
npm install
npm run dev
```

然后在 Chrome 中打开 [http://localhost:3000](http://localhost:3000)。

## 使用顺序

1. 选择要录制的屏幕、窗口或标签页。
2. 按需开启摄像头与麦克风。共享屏幕时，只有勾选浏览器提供的“共享音频”选项，系统声音才会进入成片。
3. 输入提词文案，选择“语音跟随”或“匀速滚屏”，先用“预演提词”确认效果。
4. 选择分辨率、帧率和码率后开始录制。
5. 停止录制，回看结果并下载 WebM 文件。

## 浏览器限制

- 推荐 macOS 最新版 Chrome。
- 语音跟随依赖 Chrome 的 Web Speech API 和系统默认麦克风，识别服务是否可用取决于浏览器、网络与地区。
- 浏览器拒绝语音权限时，匀速滚屏仍可使用。
- 浏览器只能请求设备支持的最高画质，摄像头不支持 4K 时会自动使用其实际分辨率。
- 高码率 4K / 60fps 对 CPU、GPU 和磁盘压力较大，建议连接电源并关闭高负载应用。
- WebM 可直接上传到多数平台；如需 MOV 或 MP4，可在录制后使用转码工具处理。
- 非 localhost 环境必须使用 HTTPS，浏览器才会开放屏幕、摄像头和麦克风权限。
